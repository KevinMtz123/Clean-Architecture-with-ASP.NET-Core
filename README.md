# 🦷 DientesLimpios — Clean Architecture with ASP.NET Core

Sistema de gestión para una clínica dental desarrollado con **ASP.NET Core**, orientado a demostrar principios de **Clean Architecture**, separación de responsabilidades y desarrollo backend mantenible.

## 🏗️ Arquitectura

```text
DientesLimpios
├── API             → Endpoints y configuración
├── Aplicacion      → Casos de uso y lógica de aplicación
├── Dominio         → Entidades y reglas de negocio
├── Identidad       → Autenticación y autorización
├── Infraestructura → Servicios externos e implementaciones
├── Persistencia    → Acceso a datos y repositorios
└── Pruebas         → Pruebas automatizadas
```

### Principios

- Separación de responsabilidades
- Inversión de dependencias
- Dominio independiente de infraestructura
- Casos de uso desacoplados
- Persistencia mediante abstracciones
- Diseño orientado a mantenibilidad

## 🛠️ Stack

- **C# / .NET**
- **ASP.NET Core Web API**
- **Entity Framework Core**
- **SQL Server**
- **Clean Architecture**
- **Pruebas automatizadas**
